# Jagannath Barik — Single Page Portfolio


### Visual applied
- Deep navy starfield background
- Purple-to-blue gradient typography
- Hero layout with content left and visual/profile area right
- **Removed the previous sun**
- Added a rounded portrait frame on the top-right
- Added a continuously moving software/technology icon row

- Responsive desktop/tablet/mobile layout


### Run
Open `index.html` directly or use VS Code Live Server.

### Deploy
The project is static and can be deployed to firebase, Vercel, Netlify or GitHub Pages.
