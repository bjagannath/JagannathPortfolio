# Jagannath Barik — Developer Portfolio

A modern, responsive, single-page developer portfolio website, focused on Python, full-stack web development, AI, databases, and project-based experience.

## ✨ Features

- 🌌 Dark space-inspired background with stars and subtle glow effects
- 👨‍💻 Personal profile section with profile photo
- 🔵 Animated rotating orbit around the profile photo
- 💻 Skills section for frontend and backend technologies
- 🧰 Software and technology showcase with animated scrolling icons
- 🚀 Project showcase with project descriptions and technology tags
- 👋 About section with personal introduction, tech stack, and coding passion
- 📩 Contact section with email and social links
- 📱 Responsive design for desktop, tablet, and mobile devices
- 🎨 Purple/blue gradient visual theme
- ⚡ Smooth scrolling and lightweight CSS animations
- 📄 Single-page layout
